Getting started

  • Connect your iPad to the same network as your WING, WING Compact or WING Rack. Find the console IP on the console under SETUP → Network.
  • No console yet? Open the built-in demo console from the Connect screen and follow the 5-minute volunteer walkthrough.
  • The optional AI chat uses your own Claude API key from console.anthropic.com (billed by Anthropic). The key is stored only in your iPad’s Keychain.

Troubleshooting

  • Cannot connect: check the IP address, that both devices are on the same network, and that the app may use the local network (iPad Settings → SoundPilot).
  • No meters: make sure Remote Lock is off on the console.
  • Something changed unexpectedly: use “Undo Last Change” or “Return to Baseline” in the emergency bar.

시작하기

  • 아이패드를 WING·WING Compact·WING Rack과 같은 네트워크에 연결하세요. 콘솔 IP는 콘솔의 SETUP → Network에서 확인합니다.
  • 콘솔이 없어도 연결 화면에서 데모 콘솔을 열고 5분 봉사자 따라 하기로 익힐 수 있습니다.
  • AI 채팅(선택)은 본인의 Claude API 키(console.anthropic.com, 요금은 Anthropic에서 청구)를 씁니다. 키는 아이패드 키체인에만 저장됩니다.

문제 해결

  • 연결이 안 될 때: IP 주소, 같은 네트워크인지, 로컬 네트워크 권한(설정 → SoundPilot)을 확인하세요.
  • 미터가 안 나올 때: 콘솔의 Remote Lock이 꺼져 있는지 확인하세요.
  • 뭔가 잘못 바뀌었을 때: 긴급 바의 ‘마지막 변경 취소’ 또는 ‘기준점 복귀’를 누르세요.
